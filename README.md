# IMCC Website Project

## Overview
This project is a Node.js/Express application with a SQLite database that serves a public website and an admin portal. It has been updated for:
- Security hardening (input sanitization, MIME type restrictions)
- Accessibility improvements and responsive design
- Progressive Web App (PWA) support
- Docker deployment configuration

## Prerequisites
- **Node.js** (v18 or later) – the project was tested with v24.21.0.
- **npm** (comes with Node) – used to install dependencies.
- **Docker** (optional) – for containerized deployment.
- **Git** (optional) – to clone the repository.

## Setup
1. **Clone / copy the project** to a location of your choice, e.g.:
   ```
   C:\Users\HP\Downloads\imcc-website-ndola-geo\imcc-website
   ```
2. **Install dependencies** (run once or after any `package.json` changes):
   ```powershell
   cd "C:\Users\HP\Downloads\imcc-website-ndola-geo\imcc-website"
   npm ci
   ```
3. **Environment variables** – the server reads the following variables:
   - `HOST` – IP address to bind to (default `0.0.0.0`).
   - `PORT` – Port number (default `3456`).
   - `ADMIN_EMAIL` – Admin contact email (optional).
   You can set them directly in PowerShell or use the helper script `run_server.ps1`.

## Running the Server Locally
### Option 1: PowerShell script (recommended)
   ```powershell
   .\run_server.ps1
   ```
   The script sets `HOST` and `PORT`, installs dependencies (if needed), and starts the server.

### Option 2: Manual command
   ```powershell
   $env:HOST = "0.0.0.0"
   $env:PORT = "3456"
   npm start
   ```

The server will listen on `http://localhost:3456`.
- Public site: `http://localhost:3456`
- Admin portal: `http://localhost:3456/admin.html`

## Docker Deployment
A `Dockerfile` and `render.yaml` are already provided.
```bash
# Build the image
docker build -t imcc-website .
# Run the container (exposes port 3456)
docker run -p 3456:3456 imcc-website
```
The container uses the same environment variables (`HOST`, `PORT`).

## Production / Cloud Deployment
The project is ready for Render, Railway, Fly.io, or any provider that can run a Docker container or a Node.js app. Make sure to set `HOST=0.0.0.0` so the service is reachable externally.

## Accessibility & PWA
- The site follows WCAG 2.1 AA guidelines (semantic HTML, ARIA labels, focus management).
- A `manifest.json` and service worker enable "Add to Home Screen" on mobile browsers.

## Troubleshooting
- **Server not reachable**: If you started the server inside Antigravity's sandbox, it can only be accessed from the same command. Use the script or run the command outside the sandbox (`BypassSandbox:true`).
- **Port already in use**: Change the `PORT` env var.
- **Database errors**: Ensure the `data/imcc.db` file has read/write permissions.

## Cleaning Up
To stop the server, press `Ctrl+C` in the terminal where it is running. Delete any temporary log files in the `logs/` folder if needed.
